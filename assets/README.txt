DJDEV.IN — image drop-in guide
================================
Place the artist photos in this folder with EXACTLY these filenames:

  dev-02.jpg — 1600 x 900  (large still)
  dev-03.jpg — 1200 x 900  (still)
  dev-04.jpg — 900 x 900   (still)
  dev-05.jpg — 900 x 900   (still)
  dev-06.jpg — 900 x 900   (still)

JPG, sRGB, quality 80-85. The gallery tiles pick them up automatically —
no code changes needed. Landscape orientation works best.
